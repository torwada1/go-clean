# Go Clean Co. website

موقع Go Clean الرئيسي — HTML وCSS وJavaScript، بدون خطوة بناء.

## المحتوى
- جاليري دائري موحد: 5 صور و20 فيديو، بصور معاينة وعناوين بالعربي والإنجليزي.
- خدمات وباقات شهرية، روابط واتساب وسوشيال، وآراء العملاء.
- حركة سلسة ودعم الموبايل والوضع الداكن وتقليل الحركة.

## التشغيل
ارفع محتويات المستودع بحيث يكون index.html في الجذر. للمعاينة المحلية يمكن استخدام أي خادم ملفات ثابتة.

## النشر
يمكن ربط المستودع بـCloudflare Pages، بدون أمر بناء، ومجلد الإخراج هو جذر المشروع. ويمكن نشره عبر GitHub Pages من الفرع الرئيسي ومجلد /(root).

## الحجز والتقييمات
هذه واجهة الموقع الرئيسي. الحجز وإدارة الحجوزات والتقييمات تستخدم الخدمة الحالية على https://go-clean-bookings.mohamedood48.chatgpt.site/؛ رفع هذا المستودع لا ينقل قاعدة البيانات ولا يغير إعدادات البريد.

## التعديل
- config.js: معلومات الشركة وروابطها والأسعار.
- gallery-data.js: قائمة الصور والفيديوهات وعناوينها وصور المعاينة.
- assets/: ملفات الوسائط.
